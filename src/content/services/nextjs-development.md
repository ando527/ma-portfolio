## What I build in code

- **Next.js and React sites** that ship as fast, static pages, with content in plain files a developer can version and review.
- **Live data from APIs.** This site's About page shows my current speedcubing results from the World Cube Association's data, cached at build time and topped up in the browser. For Speedcubing Australia I wrote the competition finder in plain JavaScript against the WCA API, so it needs no framework at all.
- **Performance work.** Image pipelines that serve the right size to every screen, scripts that only run while they're on screen, and pages that paint before JavaScript loads.
- **Accessibility and structured data.** Semantic HTML, keyboard support, visible focus, reduced-motion support and schema.org markup that ties a site together for search engines.

## When code is the right call

Webflow and Shopify cover most business websites well, and I'll say so when one of them fits. Code makes sense when a site needs custom logic, data from other systems, or full control over performance and hosting.
